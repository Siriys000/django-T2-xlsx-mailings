# Контракт импорта

Документ будет уточняться вместе с реализацией. На текущем этапе зафиксировано:

- обрабатывается активный лист XLSX;
- полностью пустые строки игнорируются;
- частично заполненные или невалидные строки считаются ошибочными;
- обязательные заголовки могут находиться в любом порядке;
- дополнительные колонки не участвуют в импорте;
- одна ошибочная строка не останавливает весь импорт;
- существующие данные не перезаписываются при повторном `external_id`.

Команда должна отдельно сообщать результаты импорта и доставки, чтобы созданная
запись с ошибкой отправки не считалась невалидной строкой XLSX.
